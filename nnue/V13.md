# NNUE Architecture Specification: Luminex V13

## 1. General Metadata
- **Network Name**: Luminex V13
- **Target Engine / Application**: Luminex (v6.2+)
- **Primary Use Case**: Chess Position Evaluation
- **Weight Quantization Scheme**: Post-hoc quantization (int16 feature transformer, int8 tail; per-channel scales)
- **Internal Output Scale**: int32 accumulator units → centipawns

---

## 2. Input Features & Transformer Layer
- **Feature Set Name**: HalfKAv2_hg-f (king-bucketed, factorized)
- **Input Feature Dimension**: `[24576]` per perspective (Sparse boolean vector)
- **Feature Breakdown**:
  1. **Feature Group 1**: HalfKAv2_hg piece-square × own-king-square (64 king squares × 384 piece-square slots)
  2. **Feature Group 2**: King-bucket factorizer — 64 king squares collapse to 4 horizontally-mirrored king buckets; factorized (virtual) features share transformer columns across buckets, multiplying coverage without multiplying weight rows
- **Perspective Symmetry**: Dual Perspective (`side-to-move` / `other-side`)

---

## 3. Perspective Accumulator Subnet
- **Input Dimension**: `[24576]` (Sparse boolean)
- **Output Dimension**: `[768]` per perspective
- **Layer Breakdown**:
  - `Sparse Linear`: Input `[24576]` -> Output `[768]` | Weights: `FP<i16>`, Bias: `FP<i16>` (saturating int16 adds; incremental update O(features flipped))
  - `Activation`: SCReLU `clamp(in, 0, QA)²`
  - **Interaction Block (V13)**: Factorization-machine latent sums per perspective
    - Per-feature latent vectors `v_i ∈ R^32` (`FP<i16>`), running sums `S = Σ v_i ∈ Z^32`, `Q = Σ ‖v_i‖²`
    - Forward-time interaction vector: `I = ½(‖S‖² − Q) ∈ R^32` (`FP<i32>`) — all pairwise feature interactions at O(1) per flipped feature; single active feature must yield exactly `I = 0`
    - Alternative candidate for this slot (gated head-to-head): forward-time elementwise products `A⊙B` of the two 384-wide accumulator halves

---

## 4. Subnet Selection & Bucketing Logic
- **Routing Factor**: Non-pawn piece count
- **Bucket Selection Logic**: `Index = (piece_count - 2) / 4`
- **Number of Buckets**: `8` (Main Subnets `0` through `7`)
- **Combined Perspective State**: Concatenated `[768 + 768 + 32 + 32]` tensor (both accumulators + both interaction vectors) fed into selected Main Subnet
- **Soft Interpolation (experiment flag)**: blend adjacent buckets by fractional phase, `eval = (1-t)·head[b] + t·head[b+1]`, instead of hard switching

---

## 5. Main Subnet Architecture

| Layer Index | Layer Type | Input Shape | Output Shape | Activation / Operation | Fixed-Point Type |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **L1** | Dense Linear | `[1600]` | `[16]` | None | `FP<i32, QA·QB>` |
| **L2** | Activation | `[16]` | `[16]` | SCReLU `clamp(0, QA)²` | `FP<i16, QA>` |
| **L3** | Dense Linear | `[16]` | `[32]` | None | `FP<i32, QA·QB>` |
| **L4** | Activation | `[32]` | `[32]` | SCReLU `clamp(0, QA)²` | `FP<i16, QA>` |
| **L5** | Dot Product | `[32]` | `[1]` | Output Dot Product with Weights | `FP<i32, QA·QB>` |

---

## 6. Output Conversion & Post-Processing
- **DOSL Linear Head (parallel, O(1))**: per-feature scalar weights summed incrementally per perspective; qsearch stand-pat reads `lin[stm]` directly without running the Main Subnet
- **Output Head**: selected (or blended) bucket head of the Main Subnet
- **Final Rescaling Formula**:
  $$
  \text{Value} = \frac{\text{int32}(in) \times \text{Multiplier}}{\text{Denominator}}
  $$
- **Final Return Type**: Signed Integer (`int32`) / Centipawns

---
