# NNUE Architecture Specification: Luminex V13

## 1. General Metadata
- **Network Name**: Luminex V13
- **Target Engine / Application**: Luminex (v6.2+)
- **Primary Use Case**: Chess Position Evaluation
- **Weight Quantization Scheme**: Post-hoc, global scales (int16 feature transformer at `FT_WSCALE = 8192`, int8 tail ±127, side projection int8); export asserts bound every requant path
- **Internal Output Scale**: int64 intermediate → int32 centipawns

---

## 2. Input Features & Transformer Layer
- **Feature Set Name**: HalfKAv2_hg-f8 (king-bucketed, factorized to 8)
- **Input Feature Dimension**: `[24576]` per perspective (Sparse boolean)
- **Feature Breakdown**:
  1. **Feature Group 1**: base HalfKAv2_hg — 32 physical king buckets × 12 piece-color planes × 64 oriented squares = 24,576; index `KingBuckets[orient(pov, ksq)] * 768 + p_idx * 64 + orient(pov, sq)` with `p_idx = piece_type*2 + (color != pov)`, `orient` mirroring by king file (kfile ≥ 4 → XOR 7) and vertical flip (XOR 56) for black — exact match to engine `halfka_idx`
  2. **Feature Group 2**: bucket factorizer — the 32 physical king buckets map onto **8 effective buckets** via `eff = min(KingBuckets[o_ksq], 7)` (the exact clamp map validated by the DCU search); each active feature contributes TWO stored rows: `bucket_row[eff*768 + plane] + shared_row[8*768 + plane]`. Stored FT rows = 8×768 + 768 = **6,912** (+1 padding), a 3.6× parameter reduction; physical active features stay ≤ 32 per perspective
- **Perspective Symmetry**: Dual Perspective (`side-to-move` / `other-side`)

---

## 3. Perspective Accumulator Subnet
- **Input Dimension**: `[24576]` (Sparse boolean)
- **Output Dimension**: `[512]` per perspective (combined `[1056]` with side vector, see §4)
- **Layer Breakdown**:
  - `Sparse Linear (factorized)`: Input `[24576]` -> Output `[512]` as the two-row sum above | Weights: `FP<i16, FT_WSCALE>`, Bias: `FP<i16>`. Incremental update: each feature flip adds/subtracts BOTH rows (2×512 saturating int16 adds — exactness matches the gen768 accumulator invariant: ClippedReLU window [0, 8192] lies 4× below int16 saturation; king moves full-refresh that perspective)
  - `Activation`: ClippedReLU `clamp(in, 0, 8192)`, requantized `min(in >> 6, 127)` for the dense input (no squaring — the DCU confirmation put ClippedReLU ahead of SCReLU in the winning lineage, and it is cheaper per eval)
  - `Side Features (V13)`: 33 scalar summaries derived from board state — piece counts (12), pawn-file occupancy per side (8+8), king file/rank per side (4), total men (1); all O(1) from engine bitboards with trivial incremental maintenance. Projection `Linear(33 -> 32)` `FP<i8>`, inputs u8 (counts ≤ 8, files ≤ 8, men ≤ 32), output clamped `[0, 127]` (unsigned dense slot; the projection bias absorbs the offset)

---

## 4. Subnet Selection & Bucketing Logic
- **Routing Factor**: none (single main subnet — the DCU search found material bucketing does not earn its cost at this scale)
- **Bucket Selection Logic**: not applicable
- **Number of Buckets**: `1`
- **Combined Perspective State** (concat order pinned): `[acc_stm(512), acc_nstm(512), side(32)]` = `[1056]`, fed to the Main Subnet

---

## 5. Main Subnet Architecture

| Layer Index | Layer Type | Input Shape | Output Shape | Activation / Operation | Fixed-Point Type |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **L1** | Dense Linear | `[1056]` | `[16]` | None — one `VPDPBUSD` u8×i8 pass over all 1056 slots (all unsigned; worst-case dot `1056 × 127 × 127 = 17,031,934`, 126× int32 headroom) | `FP<i32>` |
| **L2** | Activation + Requant | `[16]` | `[16]` | ClippedReLU in i32, store requantized i8 `min(in >> 6, 127)` | `FP<i8, 127>` |
| **L3** | Dense Linear | `[16]` | `[64]` | None | `FP<i32>` |
| **L4** | Activation + Requant | `[64]` | `[64]` | ClippedReLU in i32, store requantized i8 | `FP<i8, 127>` |
| **L5** | Dot Product | `[64]` | `[1]` | Output Dot Product | `FP<i32>` |

---

## 6. Output Conversion & Post-Processing
- **DOSL Linear Head** (parallel branch, not summed with the main output): per-feature scalar weights (`FP<i16, 32>`) over the same 24,576 index space, exact **int32** accumulator per perspective (max 32 × 32,767 = 1,048,544), `cp = lin[stm] / 32`. qsearch stand-pat reads it without running the Main Subnet
- **Perspective Average Shortcut**: None
- **Output Addition**: None (head output only)
- **Final Rescaling Formula** (int64 intermediate; Multiplier/Denominator map the head output to the sigmoid(cp/400) training scale):
  $$
  \text{Value} = \frac{\text{int64}(in) \times \text{Multiplier}}{\text{Denominator}}
  $$
- **Final Return Type**: Signed Integer (`int32`) / Centipawns

---

```text
└──► Opponent Perspective ──► Factorized Sparse Linear [512] ──► ClippedReLU+Requant ─────┤
                                                                                            └─► [acc_nstm]
[ Bitboards ] ──► Side Features (33) ──► Projection [32] ──► clamp [0,127] ──► [side]
                                                                                    │
                                                              Concat [acc_stm | acc_nstm | side] = [1056]
                                                                                    │
                                                                              Dense Linear (16)
                                                                                    │

                                                                                    │
                                                                              Dense Linear (64)
                                                                                    │
                                                                            ClippedReLU + Requant
                                                                                    │
                                                                              Dot Product (1)
                                                                                    │
                                     [ DOSL lin[stm]/32 ] ──► qsearch stand-pat only (parallel, not summed)
                                                                                    │
                                                                                    ▼
                                                                       Rescaling (int64 intermediate)
                                                                                    │
                                                                       [ Evaluation Output (cp) ]
```
