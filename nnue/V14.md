# NNUE Architecture Specification: Luminex V14

## 1. General Metadata
- **Network Name**: Luminex V14
- **Target Engine / Application**: Luminex (v7.0+)
- **Primary Use Case**: Chess Position Evaluation (residual topology)
- **Weight Quantization Scheme**: Post-hoc, global scales (int16 FT, int8 tail, int8 cross layer); export contract in §8
- **Internal Output Scale**: int64 intermediate → int32 centipawns; residual add at output

### Constants (pinned; `FP<dtype, s>` = value stored in dtype multiplied by s)
| Symbol | Value | Meaning |
|---|---|---|
| `FT_WSCALE` | 8192 | feature-transformer weight scale = SCReLU clip ceiling |
| `QA` | 8192 | activation clip bound |
| tail weight bound | ±127 (int8) | all dense layers and cross layer |
| `ACC_REQUANT_SHIFT` | 19 | accumulator-branch requant |
| `FM_REQUANT` | `clamp(Î_k >> 6, -127, 127)` | pairwise interaction requant |
| `CROSS_H_SHIFT` | 12 | cross-layer intermediate requant: `h = clamp((W·Î+b)>>12, ±127)` |
| `CROSS_OUT_SHIFT` | 7 | cross-layer output requant: `Î2 = clamp((Î⊙h+Î)>>7, ±127)` |
| `V_CLAMP` | 8191 | FM latent component bound |
| `FM_SHIFT` | 22 | FM narrowing shift |
| `LIN_SCALE` | 32 | DOSL weight scale; `lin` accumulator int32 |
| `RESIDUAL_MODE` | true | network predicts `eval − DOSL_eval`, not full eval |
| eval scale | 400 | sigmoid(cp/400) training space |
| dense-layer input range | 0..127 (u8); interaction slots ±127 zero-point u8 | §5 kernel contract |

## 2. Input Features & Transformer Layer
- **Feature Set Name**: HalfKAv2_hg-f (king-bucketed, factorized) — identical to V13
- **Input Feature Dimension**: `[24576]` per perspective (Sparse boolean)
- **Feature Index Formula**: `idx = KingBuckets[orient(pov, ksq)] * 768 + p_idx * 64 + orient(pov, sq)` (same as V13)
- **Perspective Symmetry**: Dual Perspective

---

## 3. Perspective Accumulator Subnet
- **Input Dimension**: `[24576]` (Sparse boolean)
- **Output Dimension**: `[768]` per perspective; combined `[1664]` with interaction vectors (see §4)
- **Layer Breakdown**: identical to V13 §3 (Sparse Linear, saturating int16 accumulator, SCReLU, FM interaction block)
- **Interaction Block**: FM pairwise, identical to V13 (`I_k`, `Î_k`, requant to ±127)
- **NEW — Cross Layer (V14)**: one DCN-V2-style cross on the requantized interaction vector:
  - `h = clamp((W · Î + b) >> 12, -127, 127)` — W: `[32][32]` int8, b: `[32]` int32; max intermediate ±516,128 fits int32; shift 12 maps to ≤126
  - `Î2 = clamp((Î ⊙ h + Î) >> 7, -127, 127)` — elementwise product + residual; max ±16,256; shift 7 maps to ≤127
  - Mechanism: `(Î_i × W_ij × Î_j)` terms create explicit triplewise feature interactions; the `+Î` residual preserves the pairwise signal; one cross layer adds one order of interaction beyond FM's pairwise (DCN-V2 lineage)
  - Both `Î` and `Î2` feed the concat: the tail sees pairwise and triplewise signals explicitly
  - Cost: one 32×32 int8 dot product + one 32-element elementwise multiply = ~2K MACs, negligible

---

## 4. Subnet Selection & Bucketing Logic
- **Routing Factor**: total men, kings included (range 2..32) — identical to V13
- **Bucket Selection Logic**: `m = clamp(men, 2, 32); Index = clamp((m - 1) / 4, 0, 7)` — identical to V13
- **Number of Buckets**: `8`
- **Combined Perspective State** (concat order pinned): `[acc_stm(768), Î_stm(32), Î2_stm(32), acc_nstm(768), Î_nstm(32), Î2_nstm(32)]` = `[1664]`
- **Soft Interpolation**: same experiment flag as V13

---

## 5. Main Subnet Architecture
Dense inputs: activations 0..127 (u8); interaction slots ±127 zero-point u8 (both Î and Î2). Weights int8 ±127. Worst-case dot: `1664 × 127 × 127 = 26,838,656` — 80× int32 headroom.

| Layer Index | Layer Type | Input Shape | Output Shape | Activation / Operation | Fixed-Point Type |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **L1** | Dense Linear | `[1664]` | `[16]` | None | `FP<i32>` |
| **L2** | Activation + Requant | `[16]` | `[16]` | SCReLU, store i8 | `FP<i8, 127>` |
| **L3** | Dense Linear | `[16]` | `[32]` | None | `FP<i32>` |
| **L4** | Activation + Requant | `[32]` | `[32]` | SCReLU, store i8 | `FP<i8, 127>` |
| **L5** | Dot Product | `[32]` | `[1]` | Output Dot Product | `FP<i32>` |

**NEW — Residual output (V14):** L5's output is the **residual δ**, not the full eval. The final eval is computed in §6 as `lin + δ`.

---

## 6. Output Conversion & Post-Processing
- **DOSL Linear Head** — now the **backbone**, not just a parallel branch:
  - Per-feature scalar weights (`FP<i16, 32>`) over the 24,576 index space, exact int32 accumulator per perspective
  - Must be trained FIRST to convergence (separate high-LR pass, ×500–×1000 the normal lin LR) before residual training begins
  - Its prediction is the baseline: `baseline = lin[stm] / 32`
- **Residual Add (V14's defining operation):**
  - `eval = baseline + δ` where δ = L5 output (residual network's prediction of the correction)
  - Computed in int64 (two int32 values added; no overflow)
  - During training, the target is `residual_target = Leela_eval − baseline` — a range ~±600cp instead of ~±1500cp
- **Final Rescaling**: `Value = int64(eval) × Multiplier / Denominator` (int64 intermediate)
- **Final Return Type**: `int32` / Centipawns

## 8. Training Protocol & Export Contract

### Phase 1 — DOSL backbone training (separate pass)
- Train the linear head alone on the full eval target (NOT residual)
- LR: ×500–×1000 normal (the ×5 that starved V13's head is insufficient for growing from zero)
- Expected convergence: ~200-250cp MAE (vs V13's ~300cp barely-trained)
- Output: a competent linear eval that serves as the residual baseline

### Phase 2 — Residual network training
- Freeze DOSL weights (or train jointly at low LR ×1)
- Target: `residual = Leela_eval − DOSL_prediction` (range ~±600cp vs full eval's ±1500cp)
- Same data, same power-2.6 sigmoid-space loss
- SWA over last 25%, fresh per pass
- Expected: residual MAE ~100–150cp → combined MAE ~150–170cp (better than V13's 171.5)

### Phase 3 — Trajectory delta supervision (joint with Phase 2)
- Additional loss term: `λ_traj × |Δpred − Δtarget|²` where Δ = eval(t+1) − eval(t)
- Gate on smooth positions: supervise only when |Δtarget| < 100cp
- Expected smooth fraction: 70–80% of consecutive position pairs

### Export asserts
All V13 asserts, plus:
- Cross-layer intermediate: `32 × 127 × 127 >> 12 == 126` (fits int8)
- Cross-layer output: `(127 × 127 + 127) >> 7 == 127` (fits int8)
- Residual decomposition: `DOSL_eval + residual_output ≈ full_eval` within tolerance on a held-out set
- DOSL backbone MAE < 300cp (must be a competent baseline, not a zero predictor)

## 9. Comparison with V13 and SFNNv16

| Feature | V13 | V14 | SFNNv16 |
|---|---|---|---|
| Feature interactions | FM pairwise (r=32) | FM pairwise + cross-layer triplewise | Hand-designed threat features (removed in v16 for size) |
| Topology | Parallel (DOSL + full net) | **Residual (DOSL backbone + correction net)** | Full eval only |
| Training target | Full eval (±1500cp) | **Residual (±600cp)** | Full eval |
| Quantization resolution | 127 levels / 3000cp = 23.6cp/level | **127 levels / 1200cp = 9.4cp/level** | Not published |
| Trajectory supervision | None (designed, not implemented) | **Phase 3 loss term** | None |
| Output buckets | 8 by material count | Same | More (king buckets + output) |
| King buckets | Factorized knob (4/8/16) | Same | Fixed |
| Novel components | FM block, DOSL | Cross layer, residual topology, trajectory supervision | None (frontier standard) |
