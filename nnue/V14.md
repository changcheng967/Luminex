# NNUE Architecture Specification: Luminex V14 (program — spec forms as campaigns conclude)

## Status

The original V14 spec (residual topology around a 768/FM/cross architecture,
SFNN-style mobility features) is **retired**: the DCU component campaigns
refuted its architectural basis — L1=512 with a factorized-8 FT, ClippedReLU,
and derived side features beat every 768/FM/cross shape tested, and that
winner was folded into V13's amended spec instead.

V14 is now the generation **beyond V13** and is defined by campaign evidence
as it lands. The four surviving ideas from the retired spec are campaigns,
not commitments.

## Campaigns

1. **Enriched derived features** — pawn structure (doubled/isolated), king
   shield, rook open/semi-open files, piece pairs — all from feature indices
   (running).
2. **Trajectory delta supervision** — train on eval changes along game plies
   (needs a game-grouped bench sampler).
3. **Policy multi-task** — best-move auxiliary head from the frame move
   streams (needs move targets in the bench data).
4. **Residual topology with a properly-trained lin head** — DOSL backbone +
   neural delta; the original failure was LR starvation of the lin head
   (x5 multiplier), not the topology. Requires the x500-1000 head recipe.

## Spec rule

This file becomes the template-strict V14 specification once a campaign
produces a confirmed winner (replication + long-budget confirmation, the V13
standard). Nothing enters the spec on promise.
