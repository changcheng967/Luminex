# NNUE Architecture Specification: Luminex V14

## 1. General Metadata
- **Network Name**: Luminex V14
- **Target Engine / Application**: Luminex (v7.0+)
- **Primary Use Case**: Chess Position Evaluation (residual topology)
- **Weight Quantization Scheme**: Post-hoc (int16 FT, int8 tail, per-channel L1 scales)
- **Internal Output Scale**: int64 intermediate → int32 centipawns; residual add at output

---

## 2. Input Features & Transformer Layer
- **Feature Set Name**: HalfKAv2_hg-m (mobility-augmented, king-bucketed, factorized)
- **Input Feature Dimension**: `[24616]` per perspective (Sparse boolean vector)
- **Feature Breakdown**:
  1. **Feature Group 1**: HalfKAv2_hg base — 32 king buckets × 12 piece-color planes × 64 oriented squares = 24,576; factorized across king buckets (virtual features alias physical columns)
  2. **Feature Group 2**: Mobility summary — 20 per perspective (40 total): total mobility (8 buckets), knight/bishop/rook/queen/king mobility (4 buckets each), attacked squares stm/nstm (8 each), king-zone attacks (4), hanging pieces (4); computed from engine attack maps, O(1) read
- **Perspective Symmetry**: Dual Perspective (`side-to-move` / `other-side`)

---

## 3. Perspective Accumulator Subnet
- **Input Dimension**: `[24616]` (Sparse boolean)
- **Output Dimension**: `[768]` per perspective (combined `[1664]` with interaction vectors, see §4)
- **Layer Breakdown**:
  - `Sparse Linear`: Input `[24616]` -> Output `[768]` | Weights: `FP<i16>`, Bias: `FP<i16>` (saturating int16 adds; SCReLU window [0,8192] 4× below saturation)
  - `Activation`: SCReLU `clamp(in, 0, 8192)²`, square in int32, requant `min(sq >> 19, 127)`
  - `FM Interaction`: latent `v_i ∈ R^32` (`FP<i16>`, |v|≤8191), sums `S_k`, `Q_k` in int64; `I_k = ½(S_k²−Q_k)` raw; `Î_k = I_k >> 22` (≤7934); requant `clamp(Î_k >> 6, ±127)` = +123/−4
  - `Cross Layer`: `h = clamp((W·Î+b) >> 12, ±127)`; `Î2 = clamp((Î⊙h+Î) >> 7, ±127)`; W: `[32][32]` int8; creates triplewise interactions

---

## 4. Subnet Selection & Bucketing Logic
- **Routing Factor**: Total men, kings included (range 2..32)
- **Bucket Selection Logic**: `m = clamp(men, 2, 32); Index = clamp((m - 1) / 4, 0, 7)`
- **Number of Buckets**: `8` (Main Subnets `0` through `7`)
- **Combined Perspective State**: Concatenated `[1664]` tensor: `[acc_stm(768), Î_stm(32), Î2_stm(32), acc_nstm(768), Î_nstm(32), Î2_nstm(32)]`

---

## 5. Main Subnet Architecture

| Layer Index | Layer Type | Input Shape | Output Shape | Activation / Operation | Fixed-Point Type |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **L1** | Dense Linear | `[1664]` | `[16]` | None | `FP<i32>` (per-channel scales) |
| **L2** | SCReLU + Requant | `[16]` | `[16]` | SCReLU, store i8 | `FP<i8, 127>` |
| **L3** | Dense Linear | `[16]` | `[32]` | None | `FP<i32>` |
| **L4** | SCReLU + Requant | `[32]` | `[32]` | SCReLU, store i8 | `FP<i8, 127>` |
| **L5** | Dot Product | `[32]` | `[1]` | Output Dot Product | `FP<i32>` (residual δ) |

---

## 6. Output Conversion & Post-Processing
- **DOSL Linear Head** (backbone, trained first): per-feature scalar weights `FP<i16, 32>` over `[24616]` index space; int32 accumulator per perspective; `baseline = lin[stm] / 32`
- **Residual Add**: `eval = baseline + δ` (int64 intermediate)
- **Final Rescaling Formula**:
  $$
  \text{Value} = \frac{\text{int64}(eval) \times \text{Multiplier}}{\text{Denominator}}
  $$
- **Final Return Type**: Signed Integer (`int32`) / Centipawns

---
