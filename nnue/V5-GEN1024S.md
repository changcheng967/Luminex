# NNUE Architecture Specification: Luminex gen1024s

## 1. General Metadata
- **Network Name**: gen1024s
- **Target Engine / Application**: None yet: a design under test, not in any release (LNS8 net format: an LNF8 feature table, gen768r's bucketed value tails, and one error head per output bucket)
- **Primary Use Case**: Chess position evaluation, and the evaluation's own expected error, read by the search's pruning margins
- **Weight Quantization Scheme**: QAT. The feature layer trains through the int8 grid of the LNF8 format (weights `q << 7` on the engine's x8192 domain, steps of 1/64, `|q| <= 127`; bias on the x8192 grid); the dense layers are int8 with one scale per layer per bucket, as in gen768r. The error head trains after the value net, on its frozen accumulator, through the same int8 rounding
- **Internal Output Scale**: float centipawns (trainer), int32 centipawns (engine), for both outputs

---

## 2. Input Features & Transformer Layer
- **Feature Set Name**: HalfKAv2_hm (unchanged from gen768)
- **Input Feature Dimension**: `[24576]` per perspective (Sparse boolean vector)
- **Feature Breakdown**:
  1. **Feature Group 1**: King bucket (32, horizontally mirrored) x piece-square (12 piece types x 64 squares = 768), kings included; at most 32 active rows
- **Perspective Symmetry**: Dual Perspective (`side-to-move` / `other-side`)

---

## 3. Perspective Accumulator Subnet
- **Input Dimension**: `[24576]` (Sparse boolean)
- **Output Dimension**: `[2048]` (Combined `[1024]` side-to-move + `[1024]` other side), shared by the value tail and the error head
- **Layer Breakdown**:
  - `Sparse Linear`: Input `[24576]` -> Output `[1024]` per perspective | Weights: `i8` (`q << 7` on the x8192 grid; 25.2 MB for the table, against 37.7 MB for gen768r's int16 table at 768), Accumulator and bias: `FP<i16/i32, x8192>`
  - `Activation`: SCReLU `clamp(in, 0, 1)^2` after the stm / nstm concatenation, requantized to `u8` (x127)

---

## 4. Subnet Selection & Bucketing Logic
- **Routing Factor**: Piece count (men on the board, kings included)
- **Bucket Selection Logic**: `Index = (piece_count - 1) * 8 / 32` (2-4, 5-8, ..., 29-32 men)
- **Number of Buckets**: `8`; each bucket holds a value tail and an error head
- **Combined Perspective State**: Concatenated `[2048]` tensor fed into the selected bucket's value tail, and into its error head when the search asks for it

---

## 5. Main Subnet Architecture

Value tail (per bucket, every evaluation; gen768r's widths):

| Layer Index | Layer Type | Input Shape | Output Shape | Activation / Operation | Fixed-Point Type |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **L2** | Dense Linear | `[2048]` | `[16]` | SCReLU `clamp(in, 0, 1)^2`, requantized to `u8` (x127) | `i8` weights (per-bucket scale), `f32` bias |
| **L3** | Dense Linear | `[16]` | `[32]` | SCReLU `clamp(in, 0, 1)^2`, requantized to `u8` (x127) | `i8` weights (per-bucket scale), `f32` bias |
| **Out** | Dense Linear | `[32]` | `[1]` | None | `i8` weights (own scale), `f32` bias |

Error head (per bucket, computed only where the search reads it; one linear readout, 2,048 multiply-adds):

| Layer Index | Layer Type | Input Shape | Output Shape | Activation / Operation | Fixed-Point Type |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **E1** | Dense Linear | `[2048]` | `[1]` | ReLU `max(0, in)` | `i8` weights (own scale), `f32` bias |

---

## 6. Output Conversion & Post-Processing
- **Perspective Average Shortcut**: None
- **Output Addition**: None
- **Final Rescaling Formula**:
  $$
  \text{Value} = \text{round}(out \times 300) \qquad \text{Error} = \text{round}(e \times 300)
  $$
  Error is non-negative: the predicted size of the gap between this static evaluation and a deep search's value of the position
- **Final Return Type**: Signed Integer (`int32`) / Centipawns, side-to-move relative (value); unsigned centipawns (error)

---
