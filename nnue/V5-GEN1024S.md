# NNUE Architecture Specification: Luminex gen1024s

## 1. General Metadata
- **Network Name**: gen1024s
- **Target Engine / Application**: Luminex. gen768s ([V4-GEN768S.md](V4-GEN768S.md)) at a 1024-wide feature layer; not in any release. LNB8 or LNR8 (one int8 scale per tail row, PR #89), plus the optional LHE1 heads section after the tails (PR #87)
- **Primary Use Case**: Chess position evaluation. Per position the net also gives the evaluation's expected error (the error head, read by the search's pruning margins) and the chance of a draw (the draw head, stored but not read by the search)
- **Weight Quantization Scheme**: QAT. The feature layer is on the engine's int16 grid x8192, as in gen768r and gen768s. The 8-bit table (LNF8) was tested and left out. The dense layers are int8:
  - gen1024s_01q: one scale per layer per bucket (LNB8).
  - From gen1024s_02 on: one scale per row of L2 and L3 (LNR8).

  The heads are as in gen768s: a jointly trained draw logit in the float phase, dropped before QAT, and both shipped heads fitted on the QAT net's activations (ridge regression per bucket), with int8 weights, one scale per head per bucket
- **Internal Output Scale**: value: float centipawns (trainer), int32 centipawns (engine). Heads: expected-score units in `[0, 1]`, in steps of 1/10000 in the engine

---

## 2. Input Features & Transformer Layer
- **Feature Set Name**: HalfKAv2_hm (unchanged from gen768)
- **Input Feature Dimension**: `[24576]` per perspective (Sparse boolean vector)
- **Feature Breakdown**:
  1. **Feature Group 1**: King bucket (32, horizontally mirrored) x piece-square (12 piece types x 64 squares = 768), kings included; at most 32 active rows
- **Perspective Symmetry**: Dual Perspective (`side-to-move` / `other-side`)

---

## 3. Perspective Accumulator Subnet
- **Input Dimension**: `[24576]` (Sparse boolean)
- **Output Dimension**: `[2048]` (Combined `[1024]` side-to-move + `[1024]` other side), shared by the value tail and both heads
- **Layer Breakdown**:
  - `Sparse Linear`: Input `[24576]` -> Output `[1024]` per perspective | Weights: `FP<i16, x8192>`, Bias: `FP<i32, x8192>`
  - `Activation`: SCReLU `clamp(in, 0, 1)^2` after the stm / nstm concatenation, requantized to `u8` (x127)

---

## 4. Subnet Selection & Bucketing Logic
- **Routing Factor**: Piece count (men on the board, kings included)
- **Bucket Selection Logic**: `Index = (piece_count - 1) * 8 / 32` (2-4, 5-8, ..., 29-32 men)
- **Number of Buckets**: `8`; each bucket holds a value tail and one readout of each head
- **Combined Perspective State**: Concatenated `[2048]` `u8` tensor. It feeds the selected bucket's value tail on every evaluation, and its error head when the search reads it (`HeadK > 0`). The engine never computes the draw head

---

## 5. Main Subnet Architecture

Value tail (per bucket, every evaluation; gen768r's widths):

| Layer Index | Layer Type | Input Shape | Output Shape | Activation / Operation | Fixed-Point Type |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **L2** | Dense Linear | `[2048]` | `[16]` | SCReLU `clamp(in, 0, 1)^2`, requantized to `u8` (x127) | `i8` weights (one scale per bucket in LNB8, per row in LNR8), `f32` bias |
| **L3** | Dense Linear | `[16]` | `[32]` | SCReLU `clamp(in, 0, 1)^2`, requantized to `u8` (x127) | `i8` weights (one scale per bucket in LNB8, per row in LNR8), `f32` bias |
| **Out** | Dense Linear | `[32]` | `[1]` | None | `i8` weights (own scale), `f32` bias |

Heads (per bucket; each a single linear readout with no hidden layer, 2,048 multiply-adds):

| Layer Index | Layer Type | Input Shape | Output Shape | Activation / Operation | Fixed-Point Type |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Error** | Linear readout | `[2048]` activations + `\|v\|/400` | `[1]` | clamp to `[0, 1]` | `i8` weights (one scale per head per bucket), `f32` coefficient of `\|v\|/400`, `f32` bias |
| **Draw** | Linear readout | `[2048]` activations + `\|v\|/400` | `[1]` | clamp to `[0, 1]` | `i8` weights (one scale per head per bucket), `f32` coefficient of `\|v\|/400`, `f32` bias |

`v` is the value tail's output for the same position.

---

## 6. Output Conversion & Post-Processing
- **Perspective Average Shortcut**: None
- **Output Addition**: None
- **Final Rescaling Formula**: as gen768s
  $$
  \text{Value} = \text{round}(out \times 300) \qquad e = \text{clamp}\Big(\frac{q \cdot a}{127\,s} + w_p \frac{|v|}{400} + b,\ 0,\ 1\Big)
  $$
  Here `a` is the `[2048]` activation bytes. Each head stores `round(e x 10000)`.
  - Error head: trained toward `|sigmoid(v/400) - sigmoid(t/400)|`. The search reads it as `cp = min(400, e x 400 / sigmoid'(v/400))`, with `sigmoid'` floored at 0.01.
  - Draw head: trained toward "the game was drawn".
- **Final Return Type**: value: signed integer (`int32`) centipawns, side-to-move relative. Heads: integer, 1/10000 of expected score

---

## 7. Dataflow Execution Diagram (Text Pipeline)

```text
[ Board State ]
│
├──► Side-To-Move Perspective ──► Sparse Linear [24576 -> 1024] ──┐
│                                                                  ├─► Accumulator [2048]
└──► Opponent Perspective    ──► Sparse Linear [24576 -> 1024] ──┘         │
                                                                           ▼
                                                                SCReLU clamp(0,1)^2 -> u8
                                                                           │
                                                               Bucket Routing Logic
                                                            (piece_count - 1) * 8 / 32
                                                                           │
                     ┌─────────────────────────────────────────────────────┼──────────────────────────────┐
                     ▼                                                     ▼                              ▼
        [ Value tail, bucket b ]                           [ Error head, bucket b ]          [ Draw head, bucket b ]
                     │                                     (when the search reads it)          (not computed by the
             Dense Linear (16)                                             │                         engine)
                     │                                        Linear readout + |v|/400                    │
             SCReLU clamp(0,1)^2                                           │                  Linear readout + |v|/400
                     │                                              clamp [0, 1]                          │
             Dense Linear (32)                                             │                         clamp [0, 1]
                     │                                      x 400 / sigmoid'(v/400), <= 400               │
             SCReLU clamp(0,1)^2                                           │                              ▼
                     │                                                     ▼                     [ P(draw) ]
             Dense Linear (1)                                  [ Expected error (cp) ]
                     │                                        read by the pruning margins
               x 300 -> int32
                     │
                     ▼
          [ Evaluation Output ] ──── v ────► both heads' |v|/400 input
```
