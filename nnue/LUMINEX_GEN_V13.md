## 1. 终态拓扑

```
特征层（稀疏、增量、统一连续内存）
├── 主块:    HalfKAv2_hm 24576/side
│            + KingBuckets 重映射（v1.3 新：32→可塌缩旋钮，预注册）
├── 威胁块:  SF16 剪枝子集 ~2-8K/side
│            形式由先行实验裁决（见 §5-E1）：
│            · 转换≤3/步 → 融合求和（SF 实证形态，源码验证=L1宽行求和）
│            · 转换≥5/步 → 独立 256 维切片（512B 窄行，缓存省 3-6×）
└── 兵对块:  相邻文件兵对 ~2K（并入主块；v2 时代可因子化降本——Seer 谱系）
                    │
    统一连续累加器  alignas(64) int16_t acc[2][768+256=1024]
    （物理统一：单拷贝/单预取流；逻辑分离：威胁写自己的窄切片）
    int16 饱和算术（截断窗[0,8192]=饱和界1/4，近精确——已证并入库）
                    │
    SCReLU → uint8（整数核 clamp(0,x,127)²/128, mulhi_epi16）
                    │
    concat[stm,nstm] 2048 ⊕ AUX(补零至64, 共2112=33×64 完美VNNI对齐)
    （AUX=真O(1)信号：王区3×3攻击popcount/象对/异象/易位权/王距——前置注入参与非线性）
                    ├── PSQT 线性旁路（FT 输出列直通输出——SF 同构）
                    │
    尾 L2: 2112 → 32   SCReLU+int8 VNNI（32→48→64 为 G5 后实验队列）
    尾 L3: 32 → 32     SCReLU+int8
    输出: 32 → 1 × 8 全尾材料桶子网（每节点只走 1 桶，nps 零成本；16桶王区分裂待证伪）
```

## 2. 分段宽度路径

| 级 | L1 | 参数 | 配比@现有数据 | 晋级门 |
|---|---|---|---|---|
| 0 对照 | 512 | 12.6M | 682 | — |
| **1 首训** | **768** | ~27M | 470-630 ✓ | G0-G5 全绿 |
| 2 | 1536 | ~41M | ~315 ⚠需自对弈补 | G0 数据门 + G5 + 分片累加器首选回退 |

**G0 数据门（v1.3 新）**：配比 <400 呈现/参数禁止加宽（SF 每次宽度跳变皆有数据事件喂养）。
**v13 再交易（v1.3 新）**：Step 1 特征落地后 A/B 宽度下调（768→640）— SF 学派减法考题。

## 3. 训练配方

| 步 | 内容 | 要点 |
|---|---|---|
| 单测 | **Net2Net 梯度唤醒测试**（首 batch 后新维梯度非零） | 防假阴性误触证伪条款 |
| Step 0 | Net2Net 512→768，旧特征，1 pass | **输入侧非零（复制行/小随机）+ 仅输出列置零**——严格函数保持且绕开 SCReLU 零导数死区；隔离纯宽度效应 |
| Step 1 | +威胁块（E1 裁决形式）+兵对+aux | 从 Step 0 checkpoint 续训 |
| Step 2 | λ 混合 + 蒸馏 + **QAT/STE 同步介入**（非末段） | 自对弈 1.2B WDL：多 checkpoint 混战池 + 开局随机化（防自强化偏差）+ 深度加权；λ 退火旋钮非常数 |
| Step 3 | 桶/门微调 | 骨干冻结后最后解冻 |
| 并行 | 1536 级自对弈数据生成 | 提前启动补 G0 |

损失：σ(cp/400) 空间 power-2.6（家族已证）；肥尾永不过滤。

## 4. 验收门

| 门 | 标准 |
|---|---|
| G0 | 配比 ≥400 呈现/参数（数据就位才许加宽） |
| G1 | nps ≥600K（SF19 级地板） |
| G2 | MAE ≤155（768）/≤130（1536）；predSTD ≥85%/90% |
| G3 | vs v12p2 双 TC 正 Elo，LOS≥95% |
| G4 | TC 阶梯无回退点 |
| G5 | update 占比 ≤35%，**主块/威胁块分账计量**；不过→首选回退=分片累加器，次选=停宽投尾深 |
| 证伪预注册 | 桶切换L2抖动→8桶；Leela过拟合→升λ；Net2Net无优势→纯蒸馏；KingBuckets塌缩损失评估→弃 |
